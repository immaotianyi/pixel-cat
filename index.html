Pixel Cat

8-bit 像素小猫交互组件 · 零依赖 · 可复用 · MIT 协议

★ 6 States Zero Dependency SVG + CSS ~8KB
01 · State Gallery

6 种状态：待机 / 好奇 / 行走 / 警觉 / 睡觉 / 开心。每个小猫都可以单独交互。

02 · Interactive Demo

鼠标悬停触发呼噜振动 + 星星粒子，点击触发爱心 + 对话气泡 + 嘴巴说话动画，连续点击 3 次触发开心跳舞。

Try it →

  • 鼠标移上去 → 呼噜振动 + 星星粒子
  • 鼠标移动 → 眼睛瞳孔追踪
  • 点击 → 爱心粒子 + 嘴巴说话 + 随机对话
  • 连续点击 3 次 → 开心跳舞 + 星星爆发
  • 离开后 → 自动恢复待机呼吸
03 · Semantic Speak

输入多行文本（每行一句），小猫逐句朗读。AI 自动识别每句语义 → 匹配对应动作（好奇/警觉/开心/睡觉/行走），嘴巴持续张合，身体语言跟随内容自然流动，像人讲话一样连贯。

// 联动：文本输入 → 语义分析 → 逐句朗读 + 动作编排 const cat = new PixelCat('#speakCat'); // 本地语义分析（零依赖，关键词匹配） cat.speak('你好呀\n今天好开心\n好累了，晚安', { onProgress: (i) => console.log('正在说:', i.text, '动作:', i.action), onComplete: () => console.log('说完了') }); // 方案C：寄生在桌面软件，用本地 AI 算力分析，数据足够后转外部 API cat.setSemanticAnalyzer(async (sentence) => { const res = await localAI.analyze(sentence); // 桌面端本地大模型 return { action: res.action, confidence: res.confidence }; });

05 · Programmatic API

通过 JS 直接控制状态、对话和动作。

// 创建实例 const cat = new PixelCat('#apiCat', { state: 'idle', size: 'md', autoCycle: false, idleSpeech: true, speeches: ['喵~', '好舒服~', '★ 好开心'], idlePhrases: ['...', '喵?', '~ zZ'] }); // API 调用 cat.setState('happy'); // 切换状态 cat.say('喵呜~'); // 显示对话气泡 cat.happy(); // 触发开心跳舞 cat.setSize('lg'); // 修改尺寸 cat.setSpeeches([...], [...]); // 更新台词 cat.destroy(); // 销毁实例
06 · Quick Start
<!-- 1. 引入 CSS --> <link rel="stylesheet" href="pixel-cat.css"> <!-- 2. 放一个容器 --> <div class="cat-interactive cat-idle"></div> <!-- 3. 引入 JS，自动初始化 --> <script src="pixel-cat.js"></script>
