01 · State Gallery

6 种状态：待机 / 好奇 / 行走 / 警觉 / 睡觉 / 开心。每个小猫都可以单独交互。

02 · Interactive Demo

鼠标悬停触发呼噜振动 + 星星粒子，点击触发爱心 + 对话气泡 + 嘴巴说话动画，连续点击 3 次触发开心跳舞。

Try it →

  • 鼠标移上去 → 呼噜振动 + 星星粒子
  • 鼠标移动 → 眼睛瞳孔追踪
  • 点击 → 爱心粒子 + 嘴巴说话 + 随机对话
  • 连续点击 3 次 → 开心跳舞 + 星星爆发
  • 离开后 → 自动恢复待机呼吸

04 · Broadcast Mode

口播专用模式：支持标记语法设置姿态和表情，AI 自动匹配动作，保持自然连贯。姿态持续生效直到重置，表情单次触发后消失。

[戴眼镜] 文字 → 持续姿态（眼镜/讲课/书本/键盘/展示/思考）
[疑问] 文字 → 瞬间表情（疑问/震惊/想到/点赞/否定）
[/] 文字 → 重置姿态，恢复正常说话
idle · 无姿态
待机
// 口播模式：标记语法 + 优先级引擎 + 动作密度策略 const cat = new PixelCat('#broadcastCat'); // 标记语法自动解析，姿态持续，表情单次 cat.speak('[戴眼镜]AI的本质是降低门槛\n[敲键盘]看这段代码\n[/]谢谢大家', { onProgress: (i) => console.log(i.text, i.pose, i.emote), onComplete: () => console.log('口播结束') }); // 手动控制 API cat.setPose('glasses'); // 设置持续姿态 cat.clearPose(); // 清除姿态 cat.triggerEmote('question'); // 触发瞬间表情 cat.setBubbleSize('lg'); // 气泡尺寸 sm|md|lg cat.setBubblePosition('left'); // 气泡位置 left|center|right

06 · Programmatic API

通过 JS 直接控制状态、对话和动作。

// 创建实例 const cat = new PixelCat('#apiCat', { state: 'idle', size: 'md', autoCycle: false, idleSpeech: true, speeches: ['喵~', '好舒服~', '★ 好开心'], idlePhrases: ['...', '喵?', '~ zZ'] }); // API 调用 cat.setState('happy'); // 切换状态 cat.say('喵呜~'); // 显示对话气泡 cat.happy(); // 触发开心跳舞 cat.setSize('lg'); // 修改尺寸 cat.setSpeeches([...], [...]); // 更新台词 cat.destroy(); // 销毁实例
